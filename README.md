# groupe-couture.github.io

Page d'accueil du Groupe Couture : boutons vers les applications de l'organisation.

Publiée par GitHub Pages : https://groupe-couture.github.io/

## Sites hébergés

- `levis-subaru/` → https://groupe-couture.github.io/levis-subaru/ : copie du dossier `public/`
  du dépôt privé groupe-couture/levis-subaru (seulement le site, ni le code source, ni les tests, ni les règles).
  Ne pas modifier ici : corriger dans levis-subaru, puis recopier `public/` dans `levis-subaru/`.

## Modifier

Un seul fichier, `index.html`. Pour ajouter une application, copier un bloc `<div class="card ...">`
dans le `<nav>`. Pas de build, aucune dépendance.

Ce dépôt est public (forfait gratuit de l'organisation) : n'y mettre que la page d'accueil,
seulement les fichiers de sites publiés, jamais le code source, les tests ni les règles.
